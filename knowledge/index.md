# Companii din Romania

Acest bundle documenteaza cunostinte despre structura si identitatea companiilor din Romania, intr-un format portabil si agent-friendly conform standardului Open Knowledge Format (OKF) v0.1.

## Concepte

- [Denumirea oficiala](companies/denumire-oficiala.md) - Cum identificam denumirea legala a unei firme
- [Brand](companies/brand.md) - Ce inseamna un brand si cum difera de denumirea firmei
- [Grup](companies/group.md) - Cum se organizeaza companiile in grupuri

## Despre acest bundle

Acest bundle este destinat echipelor care lucreaza cu date despre companii din Romania si au nevoie de un context structurat despre:

- Cum se numesc oficial firmele si unde verificam asta
- Diferenta dintre brand si entitate legala
- Cum sunt organizate companiile in grupuri corporatiste

Fiecare concept este documentat ca un fisier markdown independent, cu metadate YAML frontmatter, conform OKF v0.1.
